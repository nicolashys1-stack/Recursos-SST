# CV en Seguridad e Higiene — carrusel 9 placas (formato "reel viral": opinión polémica)

Estrategia: gancho de opinión impopular → identificación ("pasa todo el tiempo") → errores (auto-diagnóstico) →
antes/después → valor práctico → afirmación polémica (técnico vs ingeniero) → checklist (guardable) → cierre empático →
CTA de debate binario (TÍTULO o CV) + etiquetar a un colega. Los ejemplos de CV son ilustrativos (no son datos reales).
